### ✨ Key Subsystems Included:
1. **Model Context Protocol (MCP) Studio**: JSON-RPC 2.0 host and client engine for SQLite, Docker, and custom tools.
2. **In-Browser WASI / POSIX WebContainer**: Virtual POSIX operating system running Node.js, Pyodide, and Vite dev servers in-tab.
3. **Local Vector DB & AST PageRank Graph**: Reciprocal Rank Fusion (RRF) combining dense embeddings with sparse BM25 and AST hub centrality.
4. **Interactive Git DAG & 3-Way Merge Resolver**: Visual branch topology with 1-click conflict acceptance and real-time Git Blame.
5. **DAP Interactive Debugger**: Full Debug Adapter Protocol stepper with conditional breakpoints, logpoints, and watch expressions.
6. **Multi-Terminal Grid with "Fix with AI"**: Real ConPTY and WASI terminal sessions with split panes and automatic error patching.
7. **Hugging Face GGUF Storefront & Ollama**: 1-click download and offline caching of 1,000+ open-weights models.
8. **Universal Smooth Scrolling**: Cross-browser 60fps flex-bounded scrolling across all sidebars, trays, and tools.
9. **AI4Bharat IndicNLP Corpus & Vectors Studio**: 100% offline-ready linguistic workbench covering 12 Indian languages, 9B+ tokens, 300D FastText word embeddings, Indic tokenizers, and news classification benchmarks.
10. **Chroma AI Vector Database**: Embedded Chroma Collections and Client API with cosine, L2, and inner-product distance metrics, metadata & document filtering ($eq, $contains), and real-time RAG hybrid search fusion.
11. **Hugging Face Candle Rust ML & WASM Inference**: Minimalist, zero-Python local ML framework integration with `integrations/candle`. Supports in-browser WebAssembly SIMD execution, serverless LLM generation (Qwen2.5-Coder, LLaMA-3.2, Phi-3.5 Mini), zero-Python local Whisper speech-to-text, and fast BERT dense semantic embeddings.
